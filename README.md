# VAICH AI Gateway

Build a professional, modern and premium Persian e-commerce website for a brand called "VAICH".



The website sells AI subscriptions and AI accounts, including Gemini, ChatGPT and Claude.



IMPORTANT:

- The website language must be Persian (Farsi).

- The entire UI must support RTL layout.

- Make the website fully responsive and mobile-first.

- The design must look like a premium modern AI/technology startup, not a generic online store.

- Use the provided VAICH/YH logo as the main brand logo.



BRAND STYLE:

Brand name: VAICH

Logo: YH futuristic neon logo

Main colors:

- Deep black

- Very dark navy

- Neon purple

- Neon electric blue

- White

Use purple and blue gradients carefully.

Avoid excessive colors.

Use subtle glowing effects.

Use glassmorphism only where it improves the design.



DESIGN:

- Minimal

- Futuristic

- Premium

- Clean

- Professional

- Dark theme

- Rounded corners everywhere

- Smooth micro-animations

- Soft neon glow

- Beautiful typography

- Excellent spacing

- No visual clutter



HEADER:

Create a sticky modern navigation bar.



Left/right depending on RTL:

- VAICH logo

- Home

- AI Subscriptions

- Why VAICH

- FAQ

- Support



Add a prominent "خرید اشتراک" button with a purple/blue neon gradient.

"مشاهده محصولات"



Secondary CTA:

"پشتیبانی"



Add a futuristic abstract AI visual using neon blue and purple lighting.

IMPORTANT:

TECHNICAL REQUIREMENTS:

- Clean modern code

- Responsive on mobile, tablet and desktop
